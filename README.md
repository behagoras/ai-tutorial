# Claude Code vs. Cursor: A Quick-Start Course

A fast, side-by-side orientation to two AI coding tools, for an experienced developer who wants to know what each can do and when to reach for which. No programming fundamentals, no fluff — just capability mapping.

**Time budget:** all 6 files, under an hour.

## Who this is for

You're fluent with git, the terminal, and code editors. You want to know: what does Claude Code do, what does Cursor do, where do they overlap, where does each pull ahead, and how do I pick the right one for a given task (or use both).

## How to work through it

Read in order — each lesson builds on the mental model from Lesson 0. Every lesson ends with a short **Try it** exercise against your own repo; actually run it, that's where the tool differences become obvious.

1. [Lesson 0 — Setup & mental model](./00-setup-and-mental-model.md)
2. [Lesson 1 — Editing & generation](./01-editing-and-generation.md)
3. [Lesson 2 — Context & steering](./02-context-and-steering.md)
4. [Lesson 3 — Automation & power features](./03-automation-and-power-features.md)
5. [Lesson 4 — Comparison & when to use which](./04-comparison-and-when-to-use-which.md)
6. [Cool skills](,/skills.md)

Skip nothing on the first pass — each lesson is 5-10 minutes. After that, use Lesson 4's table as your reference card.
